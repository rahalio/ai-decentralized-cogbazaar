# Cogbazaar — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Research lead

- As a research lead, I want to budget a job across data + kernel + compute in one cart, so that procurement matches how experiments actually run.
- As a research lead, I want PoCW before payment clears, so that I am not paying for idle reserved GPUs that never trained.

### Kernel publisher

- As a kernel publisher, I want per-execution royalties, so that releasing a model into the bazaar is economically rational.
- As a kernel publisher, I want to restrict licence classes (research-only vs commercial), so that dual-use risk is contractually bounded.

### Compute provider

- As a compute provider, I want to bid capacity against job specs, so that my GPUs earn on cognitive work rather than hash lotteries.
- As a compute provider, I want clear PoCW formats, so that I know what evidence unlocks payment.

### Research fund administrator

- As a fund administrator, I want PoR metrics tied to disbursements, so that sponsored research is accountable.

### Compliance officer

- As a compliance officer, I want to block listed kernel categories, so that the bazaar does not become a dual-use blind spot.
- As a compliance officer, I want agent spend caps, so that autonomous buyers cannot drain the treasury.
